# Python Auto Company

AI platform that automatically generates complete software projects from natural language.

## Features
- Multi-agent pipeline: Planner, Architect, Backend, Frontend, Database, Docker, Testing, Docs, Review, Fix.
- Supports: FastAPI, Django, Telegram bots, Discord bots, CLI, Desktop, REST APIs, Microservices.
- Output includes: backend, frontend, database schema, Docker, CI/CD, tests, docs – ready to run.

## Quick Start

1. Clone repository
2. Copy `.env.example` to `.env` and set your OpenAI API key
3. Run `docker-compose up -d`
4. Open http://localhost:80
